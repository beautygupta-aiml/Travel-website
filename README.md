# Travel Explorer
## Project Description
Travel Explorer is a responsive travel website designed to help users explore popular destinations and choose suitable travel packages. The website provides a simple, clean and user-friendly interface for discovering travel options and sending enquiries.
## Features
- Responsive design for desktop, tablet and mobile devices
- Popular destinations with attractive destination cards
- Travel packages with pricing and package details
- About/Why Choose Us section
- Contact and enquiry form
- Smooth navigation between sections
- Hover effects for an interactive user experience
- Clean and user-friendly interface
## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Responsive Web Design
